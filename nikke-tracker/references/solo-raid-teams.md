# 单人突击（个突 / Solo Raid）配队

与异常拦截的根本区别：异拦是五个固定 Boss、弱点固定；**个突每赛季换 Boss，属性与弱点必须当季现查**，套用上一季结论必然整队错位。

## 规则与约束

- 最多 5 队，同一名妮姬只能用一次 → 爆裂 II 与皇冠是全库最稀缺资源：先决定哪队最需要生存，其余队换替代（女仆马斯泰 / 娜嘉 / 牡丹 等）。
- 挑战模式全员同步 400 级，练度差异只体现在技能等级、词条阶级与收藏品。
- 出队前做一次全局点名，同一角色不能重复出现，也不要因为“另一队需要”就直接挪用而不做说明。

## 当季 Boss 数据查证顺序

1. **官方赛季公告**（官号 Facebook / X）确认赛季号、Boss 名、开放时间——先锁定“本期是哪个 Boss”这一事实，再谈配队。
2. **`https://enikk.app/soloraid/<赛季号>`**：给出 Element / Weakness / 各部位 HP / 技能列表，含“护罩期只有某属性可造成伤害”“必须用特殊拦截打断”这类致命机制，是最可靠的机制源。用浏览器 `new_tab` + `js("document.body.innerText")` 读；抓取器可能因 URL 网络地址校验拒掉该域，别在提取器上反复试，直接换浏览器。
3. **GameKee** `/v1/content/list` 找当季机制讲解与推荐队伍页，用做机制复述与阵容参考。
4. prydwen 的 Solo Raid guide 常挂 Cloudflare 人机验证，拿不到就回退到上面两个来源，不要卡在验证页。

## 从玩家进度出队

1. 读 `data/nikke/player_progress.json` 拿技能与强化等级，读 `targets.json` 拿属性/职业/爆裂/武器——只认核实过的字段。
2. 按 Boss 弱点筛同属性输出，按 技能等级 → 有效词条数 排序，取前 2–3 名分散到不同队，避免主C 挤在一队。
3. 每队按 B1 / B2 / B3 成轴：B1 辅助或副C、B2 后盾（皇冠优先）、B3 主C；再补 1 辅助 + 1 副C。
4. **机制要求某属性才能破盾/造成伤害时，每队都必须塞一名该属性角色**，哪怕他不是主C——否则该队在护罩期整段空转，表面阵容正常、实际打不出伤害。
5. 技能仍是 `1/1/1` 的对策主C 只当破盾工具人或残阵，如实写“技能拉起来再换”。
6. 输出：`队伍 | 阵容（B1/B2/B3）` 表格 + 几条要点（哪队最稳、哪队薄弱、缺谁、无敌/护盾留给哪个阶段），不写长篇机制讲解。
